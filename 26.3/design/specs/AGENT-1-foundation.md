### 9. `/aircraft` test command (`commands/AircraftCommand`, permission level 2, console-friendly)

Every subcommand works from the console (no player needed). Feedback goes through `sendSuccess`, which
prints to the console, and every terminal or measured line is also logged at `INFO` so `console.log`
carries it.

| subcommand | effect |
|---|---|
| `spawn <type> <x y z> [heading]` | `type` in `plane large cargo helicopter fighter airliner airship mini_helicopter quadcopter`. Creates the entity at `x y z`, facing `heading` (deg, default 0), sets `yRot`, `yRotO`, `Q`, `Q_Client`, `Q_Prev` from the heading as `GunshipCommand.spawn` does; for every `PlaneEntity` fits a furnace engine with 64 coal (`addUpgradeUsingWrench`, `engine.container.setItem(0, new ItemStack(Items.COAL, 64))`) so `isPowered()` is true with nobody aboard; tags it `aircraft-test`; prints and logs `Aircraft #<id> <type> spawned at x, y, z heading h`. Chunks: force-load a 3-chunk radius around the spawn point for 20 s (`addTicketWithRadius(TicketType.ENDER_PEARL, ...)` renewed from a server-tick registry, as `PlaneAutopilot.keepChunksLoaded` does) and keep renewing it around every tagged aircraft while it exists; that is what makes an unmanned test flight survive without `forceload` |
| `set <id> throttle <0..10>` | `setThrottle` |
| `set <id> pitch <-1..1>` | `setPitchUp((byte) sign)` |
| `set <id> yaw <-1..1>` | `setYawRight((byte) sign)` |
| `set <id> roll <-1..1>` | `setTestStrafe((byte) sign)` |
| `set <id> cyclic <fwd> <right>` | helicopters only (`HelicopterEntity` and subclasses): `setCyclicForward(fwd)`, `setCyclicRight(right)` in percent, -100..100; "not a helicopter" otherwise |
| `set <id> boost on\|off` | helicopters only: `setCollectiveBoost` |
| `launch <id> <speed> [pitchDeg]` | `setDeltaMovement` along the heading (and pitch) at `speed` b/t |
| `hold <id> <y>` | altitude-hold test pilot, ticked from the registry before the entity ticks: `pitchTarget = clamp(0.5 * (y - plane.getY()) - 60 * vy, -15, 15)` deg, `setPitchUp(sign(pitchTarget - xRot))` with a 0.3 deg deadband. `hold <id> off` stops it |
| `trim <id> <pitchDeg>` | holds the nose at a fixed pitch the same way; `trim <id> off` |
| `takeoff <id>` | scripted: throttle 5, pitch 0 until `|v| >= takeOffSpeed` (read through a new `public double testTakeOffSpeed()` on `PlaneEntity` returning `getMotionVars().takeOffSpeed`), then pitch up held until `y - y0 > 1.0`; reports and logs `Aircraft #id rotation at N.N blocks (t ticks), airborne at M.M blocks (t ticks) at v.vv b/t pitch p.p` and then `hold`s at `y0 + 30` |
| `status [id]` | one line per tagged aircraft: `#id type pos=x,y,z spd= vs= hdg= pitch= roll= thr= og= agl=` (`agl` from the `MOTION_BLOCKING` heightmap) |
| `trace <id> on|off` | per-tick line `trace #id t= pos= spd= vs= hdg= pitch= roll= thr= og= agl=` logged at `INFO` (`String.format(Locale.ROOT, ...)`), independent of any system property so it can be switched at run time; also honour `-Dsimpleplanes.aircraft.trace=true` as "on for every spawned aircraft" |
| `kill` | removes every `aircraft-test`-tagged entity in loaded chunks and clears the registry; prints the count |

`hdg` is the nose yaw, `pitch` the nose pitch (positive up, the mod's convention), `roll`
`rotationRoll`. For the quadcopter, `status` prints its own fields (`state`, `L`, `carrying`) and the
`set`/`hold`/`trim`/`takeoff` subcommands answer "not a plane".
